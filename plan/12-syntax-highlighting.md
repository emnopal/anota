## Recipe: add a language
1. `scripts/vendor-grammars.sh`: add a `fetch` + `grammar` + `query` line; run it.
2. `Package.swift`: add its `parser.c` (+ `scanner.c`) to the `TreeSitterGrammars` sources.
3. The script's header block: declare `tree_sitter_<lang>()`.
4. `TreeSitterEngine.init`: add a `case`; add the `Language` case if new; add a row to the `codeGrammars` test.
